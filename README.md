# Vaishvik Kothia — Portfolio

Personal portfolio for business development, marketing and sales in chemical, pharmaceutical and specialty chemical industries.

Built with Jekyll and the official Slate theme. Custom responsive layout, supplied portrait and downloadable resume.

## Publishing
Upload all files to the repository root. Settings → Pages → Deploy from a branch → main → / (root).

## Editing
- index.html: content and page layout
- portfolio.css: custom design and mobile layout
- style.scss: official Slate theme import
- _config.yml: Jekyll theme and metadata
- headshot.jpg: optimized supplied portrait
- vaishvik-kothia-resume.pdf: supplied resume including original contact information

For local Jekyll preview with Ruby and Bundler installed: bundle install, then bundle exec jekyll serve.

Content is based on the supplied resume and stated career focus. The full LinkedIn profile was unavailable for verification; the site links directly to it.

Theme: https://github.com/pages-themes/slate
